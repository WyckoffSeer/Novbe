# Disclosure

## AI models
- Runtime LLM: Anthropic Claude via the `anthropic` SDK. Model name from env `NOVBE_MODEL`, default `claude-sonnet-5-5`. The exact model used for the reported evaluation is recorded in `eval/results/results.json` (`summary.model`).
- The LLM is used only to (1) translate rule sentences into typed constraints, (2) word explanations of facts computed in code, (3) act as the chatbot baseline in the eval, and (4) optionally paraphrase eval sentences. It never produces the Növbə schedule.
- All LLM calls use temperature 0 and pydantic validation with one retry.

## Data
- Fully synthetic. `data/shop_staff.json` (12 fictional staff) and `data/demo_rules.txt` were written by hand for the demo.
- Evaluation cases are generated by `eval/gen_cases.py` (seeded, reproducible) from ground-truth constraints and templates. No real people, no personal data.
- Nothing is stored or logged beyond the session.
