# Növbə — notes for Claude Code

Plain-language shift rules (AZ / RU / mixed) -> confirmed constraints -> CP-SAT schedule -> independent verification.

Hard rules (do not break):
1. The LLM never produces a schedule. It only converts text to constraints (`novbe/parser.py`) and phrases explanations (`novbe/explain.py`).
2. `novbe/verifier.py` must not import solver code.
3. Parsed constraints are shown and confirmed before solving.
4. Every sentence ends as exactly one of constraint / ambiguous / unsupported.
5. Numbers in `docs/TESTING.md` come only from `eval/results/` (generated by `eval/run_eval.py`).
6. Synthetic data only.
7. LLM calls: temperature 0, pydantic validation, one retry, then fail loudly (`novbe/llm.py`).

Dev:
- venv: `.venv/Scripts/python.exe` (Python 3.12 on this machine; ortools pinned to 9.12 because 9.15 segfaults on Windows).
- Tests: `.venv/Scripts/python.exe -m pytest -q`
- App: `.venv/Scripts/streamlit run app.py`
- Env: `ANTHROPIC_API_KEY`, `NOVBE_MODEL` (default `claude-sonnet-5-5`), or a `.env` file.
